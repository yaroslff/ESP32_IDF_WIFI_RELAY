## 🏗 Архитектура проекта

Проект имеет модульную структуру. Каждый логический блок вынесен в отдельный компонент для удобства чтения, тестирования и масштабирования:

*   **`wifi_manager.cpp/h`** — Управление сетевыми подключениями (Wi-Fi). Обработка переподключений и событий сети.
*   **`http_handlers.cpp/h`** — Реализация REST API и раздача статических файлов. Обработка запросов от Web-интерфейса (настройка Wi-Fi, MQTT, управление реле).
*   **`mqtt_handlers.cpp/h`** — Клиент MQTT. Публикация телеметрии и подписка на топики для удаленного управления устройством.
*   **`gpio_tasks.cpp/h`** — Низкоуровневая работа с периферией (управление реле, опрос кнопок/сенсоров уровня воды).
*   **`spiffs_manager.cpp/h`** — Инициализация и монтирование файловой системы SPIFFS для работы с файлами настроек и Web-UI (находятся в папке `/data`).

## 🌐 Web-интерфейс

Устройство оснащено встроенным веб-сервером, страницы которого хранятся во Flash-памяти (SPIFFS). Реализованы следующие панели управления:
*   `index.html` — Главный дашборд состояния устройства.
*   `wifiset.html` — Настройка учетных данных Wi-Fi.
*   `mqttset.html` — Конфигурация подключения к MQTT-брокеру.
*   `relay.html` — Ручное управление каналами реле.
*   `water.html` — Отслеживание показаний датчиков (например, уровня воды).
*   `ota.html` — Страница для загрузки и прошивки новых версий `.bin` файлов "по воздуху".
