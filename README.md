 Это базовый проект для устройств на ESP32 с веб интерфейсом. Веб интерфейс устроен по принципу обычного веб сервера,
файлы загружаются в папку data, и код сразу начнет их отдавать по их адресам.

Так же базово реализовано подключение к MQTT.

Устройство запускается с точкой доступа WIFI для первичной настройки, дальше можно ввести данные домашней точки доступа,
 после автоматической перезагрузки подключится к ней. При потере связи, вновь появится точка доступа ESP32.
