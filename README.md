# ESP32 Universal Web Server & Relay Controller

## Цель проекта
Создание универсального модульного веб-сервера на базе микроконтроллера ESP32 для удаленного и локального управления периферийными устройствами (4 реле)[cite: 5]. Проект разработан как гибкая платформа для систем автоматизации с поддержкой беспроводной настройки и интеграции по протоколу MQTT[cite: 5].

## Ключевые возможности
* **Управление нагрузками:** Локальное и удаленное переключение 4 независимых каналов реле через веб-интерфейс или MQTT-команды[cite: 5].
* **Гибкая настройка сети:** Поддержка работы в режиме Wi-Fi клиента (STA) или точки доступа (AP), сканирование доступных сетей «по воздуху» и сохранение параметров в энергонезависимую память (NVS)[cite: 5].
* **Интеграция с MQTT:** Подключение к внешним брокерам с возможностью настройки параметров подключения через веб-панель[cite: 5].
* **Двойное OTA-обновление:** Защищенное обновление прошивки (app) и файловой системы (SPIFFS) через веб-браузер[cite: 4].
* **Recovery-режим:** Встроенная в код аварийная страница обновления, защищающая устройство от сбоев при повреждении файловой системы[cite: 5].

## Стек технологий
* **Фреймворк:** ESP-IDF (C/C++)[cite: 5].
* **Сеть и протоколы:** HTTP-сервер, Wi-Fi, MQTT[cite: 5].
* **Хранение данных:** NVS (для конфигураций) и SPIFFS (для веб-интерфейса)[cite: 5].
